# NoteX Mobile — React Native + Expo Application

> **Shared Supabase Backend:** `https://bekstvkypwgxgpstpmri.supabase.co`

This is the mobile application for NoteX, matching Phase 11 of the Master Development Specification.

---

## 📱 Mobile Screens Included
1. **Home Screen:** Hero branding, branch chips (`CSE`, `ISE`, `ECE`, `EEE`, `Mech`), and trending notes.
2. **Explore Screen:** Real-time search by subject, code, branch, and semester.
3. **Note Detail Screen:** Syllabus breakdown, page count, and purchase actions.
4. **Mock Checkout Modal:** Transparent ₹10 commission deduction and simulated success/failure.
5. **My Library Screen:** Purchased notes, licensed student verification badge.
6. **Protected Canvas Viewer:** Dynamic diagonal watermarking overlay (`LICENSED TO: [NAME]`, `NOTEX ID: NTX-XXXXX`).
7. **Creator Studio Screen:** Balance tracker and note submission form with private storage.
8. **Student Profile Screen:** Profile details, VTU university details, and security status.

## 🚀 How to Run Locally

### 1. Navigate to Mobile Folder
```bash
cd mobile
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Expo Dev Server
```bash
npx expo start
```

- Press `a` for **Android Emulator**
- Press `i` for **iOS Simulator**
- Or scan the QR code with the **Expo Go** app on your physical mobile device!
